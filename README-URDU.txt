رانا فارم کھاتہ — ابتدائی ورژن
================================

یہ ورژن کیا کرتا ہے؟
- اپنی مرضی سے زمین/پیلی شامل کرنا، ایکڑ، ملکیت، فصل اور ٹھیکہ درج کرنا۔
- ہر پیلی کے لیے اخراجات درج کرنا، مثلاً بیج، کھاد، اسپرے، ڈیزل، پانی، مزدوری، کٹائی وغیرہ۔
- فصل کی فروخت، آڑھتی، کمیشن، وصول شدہ رقم اور باقی رقم درج کرنا۔
- آڑھت/ادھار/وصولی کے الگ کھاتے بنانا۔
- ہر پیلی کا خرچہ، فروخت اور منافع/نقصان؛ تمام پیلیوں کی مجموعی رپورٹ۔
- بیک اپ JSON فائل ڈاؤن لوڈ اور واپس درآمد کرنا۔
- PWA کے ذریعے موبائل پر ایپ جیسا استعمال اور آف لائن چلانے کی بنیاد۔

اہم حد:
یہ ابتدائی ورژن ڈیٹا اسی ڈیوائس/براؤزر کے localStorage میں رکھتا ہے۔ یہ ابھی متعدد موبائلوں کے درمیان خودکار کلاؤڈ سنک، آن لائن لاگ اِن، سبسکرپشن/ادائیگی یا اشتہارات کا نظام نہیں ہے۔ صرف ویب سائٹ انٹرنیٹ پر اپ لوڈ کرنے سے ڈیٹا دوسرے لوگوں کے ساتھ شیئر نہیں ہوگا۔ اس کے لیے اگلے مرحلے میں Firebase/Supabase ڈیٹا بیس، صارف اکاؤنٹس اور سیکیورٹی رولز جوڑنے ہوں گے۔ حساس کاروباری ریکارڈ کے لیے باقاعدہ بیک اپ ضرور رکھیں۔

VS CODE میں چلانے کا طریقہ
1. ZIP فائل Extract کریں۔
2. VS Code کھولیں: File > Open Folder، پھر Rana_Farm_Khata فولڈر منتخب کریں۔
3. بہترین طریقہ: VS Code میں Extensions (بائیں جانب چار مربع) کھولیں، Live Server تلاش کریں اور اسے انسٹال کریں۔ پھر index.html پر right-click > Open with Live Server۔
4. اگر Live Server نہ لگانا چاہیں تو Python دستیاب ہونے کی صورت میں ٹرمینل میں یہ کمانڈ چلائیں:
   python -m http.server 8000
   پھر براؤزر میں http://localhost:8000 کھولیں۔
   Service Worker/PWA کے لیے localhost یا HTTPS درکار ہے؛ فائل پر سیدھا double-click کرنے سے آف لائن ایپ کے تمام فیچر درست کام نہیں کریں گے۔

موبائل پر استعمال
- پہلے ویب سائٹ HTTPS ہوسٹنگ پر اپ لوڈ کریں۔
- موبائل Chrome میں سائٹ کھولیں۔
- تین نقطوں والے مینو میں Install app یا Add to Home screen منتخب کریں۔
- پہلے ایک مرتبہ آن لائن کھولیں، پھر کچھ حصے آف لائن بھی چل سکتے ہیں۔

مفت ہوسٹنگ: GitHub Pages (اسٹیٹک سائٹ)
1. GitHub پر اکاؤنٹ بنائیں اور نیا public repository بنائیں، مثلاً rana-farm-khata۔
2. اس فولڈر کی تمام فائلیں repository میں upload کریں (ZIP کو بطور ZIP اپ لوڈ نہ کریں؛ پہلے Extract کریں)۔
3. Repository > Settings > Pages کھولیں۔
4. Build and deployment میں Deploy from a branch منتخب کریں، branch main اور folder /(root) منتخب کرکے Save کریں۔
5. چند منٹ بعد GitHub Pages ایک ویب ایڈریس دے گا۔ وہ HTTPS ایڈریس موبائل پر کھولیں۔
نوٹ: GitHub Pages صرف ویب سائٹ فائلیں ہوسٹ کرتا ہے؛ یہ خودکار مشترکہ ڈیٹا بیس نہیں دیتا۔

ڈیٹا بیک اپ
- اوپر “بیک اپ ڈاؤن لوڈ” باقاعدگی سے دبائیں۔
- بیک اپ فائل محفوظ رکھیں۔
- نئی ڈیوائس یا براؤزر میں اسی ایپ کو کھول کر “بیک اپ واپس لائیں” استعمال کریں۔
- بیک اپ درآمد کرنے سے موجودہ ڈیٹا بدل جائے گا، اس لیے پہلے موجودہ ڈیٹا کا بیک اپ ضرور لیں۔

اہم حسابی نوٹ
- اخراجات میں “کل رقم” مکمل خرچ درج کریں اور “ادا شدہ رقم” بتائے کہ اس میں سے کتنا ادا ہوا۔
- فصل کی فروخت میں کل فروخت، کمیشن/کٹوتی اور وصول شدہ رقم الگ درج کریں۔
- کھاتے کے اندراجات کو دوبارہ خرچے کے طور پر درج کرنے سے دوہرا حساب بن سکتا ہے۔ اس لیے ادھار کھاتے اور فصل کے خرچے کی انٹری ایک دوسرے سے سوچ سمجھ کر کریں۔
- یہ ابتدائی MVP ہے۔ کاروبار میں باقاعدہ استعمال سے پہلے اپنے اصل حسابات کے ساتھ جانچ کریں۔
